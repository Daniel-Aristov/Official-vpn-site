# Official VPN Site

Адаптивный сайт сервиса OFL VPS, свёрстанный по макетам Figma. Главная страница содержит описание возможностей, тарифы, ленту стран с флагами, инструкцию подключения и FAQ. Реализованы оформление подписки, экраны результата оплаты и контакты поддержки.

## Стек

React, TypeScript, Vite, Tailwind CSS и React Router. Для проверки кода используются ESLint и Prettier.

## Запуск

```bash
npm ci
npm run dev
```

Другие команды:

- `npm run build` — проверка TypeScript и сборка в `dist`.
- `npm run preview` — локальный просмотр сборки.
- `npm run lint` — проверка кода линтером.
- `npm run format` — форматирование проекта.

## Страницы

- `/` — главная страница.
- `/subscribe` — выбор тарифа, ввод почты и выбор способа оплаты.
- `/subscribe/success` — успешная оплата и данные подключения.
- `/subscribe/error` — ошибка оплаты и обращение в поддержку.
- `/offer` — проект оферты.
- `/data-processing` — информация об обработке данных.
- `/privacy` — проект политики конфиденциальности.

Тариф можно передать через параметр `plan`, например `/subscribe?plan=3`.

Для прямого открытия маршрутов на Netlify в `public/_redirects` настроены [правила маршрутизации](https://docs.netlify.com/manage/routing/redirects/rewrites-proxies/). Существующие маршруты получают HTML со своими метаданными, остальные обрабатываются приложением и перенаправляются на главную. При размещении на другом сервере нужно повторить эти правила.

## SEO

В `.env` используется одна переменная: `VITE_SITE_URL=https://oflvpn.com`. После смены домена нужна новая сборка.

Метаданные находятся в `src/lib/seo.ts`: заголовки, описания, canonical, Open Graph и JSON-LD с тарифами. Vite подставляет их в HTML существующих маршрутов и создаёт `robots.txt` и `sitemap.xml`. Индексируется главная; оформление, результаты оплаты и пока не утверждённые документы имеют `noindex, follow`. При переходах метаданные обновляются в `App.tsx`. Содержимое страниц отрисовывается React в браузере; отдельной SSR-сборки нет.

Тексты документов и поля реквизитов находятся в `src/data/legalDocuments.ts`. Реквизиты владельца пока не предоставлены. Перед публикацией нужно заполнить реквизиты, подтвердить инфраструктуру, сроки хранения данных и условия реальной оплаты. Структура текстов сверена с [правилами об оферте](https://base.garant.ru/10164072/a3658cc91ecf4ccb41c4de1539a49522/), [основаниями обработки персональных данных](https://www.consultant.ru/document/cons_doc_LAW_61801/315f051396c88f1e4f827ba3f2ae313d999a1873/) и [правом потребителя на отказ от услуги](https://legalacts.ru/doc/ZZPP/glava-iii/statja-32/); применимая юрисдикция требует уточнения владельцем.

## Структура

- `src/pages` — страницы приложения.
- `src/components` — компоненты интерфейса; `icons` — TSX-иконки, `subscription` — компоненты оформления подписки.
- `src/hooks` — логика меню, якорной прокрутки и показа предложения.
- `src/data` — тарифы и контакты поддержки.
- `src/styles/index.css` — базовые стили, цвета и настройки Tailwind CSS.
- `public/assets` — изображения и SVG-флаги; `public/fonts` — локальные шрифты.
